# Select automation thresholds from error budgets

Confidence thresholds will be selected from a held-out, versioned benchmark to maximize automation subject to action-specific harm limits rather than being chosen as universal constants. The portfolio target is zero observed false pages, at least 95% precision for automatic Incident creation, at least 97% precision for automatic Evidence Links, and a Corroborating Fact for every automatic page; uncertainty intervals will be reported, and any action that misses its constraint remains human-reviewed.
