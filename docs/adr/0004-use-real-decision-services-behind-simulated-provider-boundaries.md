# Use real decision services behind simulated provider boundaries

The portfolio MVP will call the real Jev API and a real generative LLM, persist durable records, and process work asynchronously, while monitoring, ticketing, deployment, and paging providers will be simulated behind realistic adapters. This preserves credible decision and failure behavior without letting third-party account setup obscure the project's primary demonstration of trustworthy AI-powered backend design.

The MVP represents one fictional multi-service SaaS organization with a fixed, versioned priority and ownership taxonomy. It will not implement multi-tenancy or taxonomy administration.

The live demonstration ends after ingestion, normalization, Jev judgments, policy evaluation, automated action or human review, Incident creation or evidence linking, audit inspection, and a cited generated summary or status draft. Later Incident lifecycle transitions remain minimal domain behavior rather than part of the featured demo.
